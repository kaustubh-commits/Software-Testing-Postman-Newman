How it works · what Newman does for every request

Idle
  1. 1RequestNewman takes the next request from the collection
  2. 2Pre-request scriptJS that runs first, e.g. make a unique USN
  3. 3API callHTTP request sent to the FastAPI server
  4. 4ResponseStatus, headers, body and time come back
  5. 5Test scriptspm.test() assertions check the response
  6. 6ReportResults go to the CLI, htmlextra and this page
